- **Контекст**: воркшоп передбачає генерацію reference-skill через `npx repomix --skill-generate` для навігації AI по репо.
- **Рішення**: згенеровано пакет у `.cursor/skills/repomix-generated-docs/` (`--skill-output`), дописано `SKILL.md` під Excalidraw і роботу з `docs/*`.

## 2026-03 — Розділення ролей `docs/` і `dev-docs/`

- **Контекст**: у репо є дві “зони” документації: `docs/` (SSD + Memory Bank + PRD/архітектура) і `dev-docs/` (оригінальна Docusaurus-документація для інтеграторів та API). Дублювання повних API-таблиць у двох місцях швидко веде до розсинхрону.

- **Наслідки**: `docs/` стає компактним “порталом процесу”, а `dev-docs/` — джерелом деталей по API; при зміні API треба перевіряти обидві сторони за sync-checklist у `docs/spec/SSD.md`.
