# Spec: Markdown hyperlinks in text elements (#11024)

## Goal

Render `[label](url)` in standalone text elements as clickable underlined links that open in a new browser tab.

## Context

- Issue: https://github.com/excalidraw/excalidraw/issues/11024
- Current behavior: `[Docs](https://example.com)` appears as literal characters.
- Expected: `Docs` is drawn as a link; click opens the URL safely.

## Component / Module

- `packages/element/src/renderElement.ts` — canvas rendering for text.
- `packages/element/src/markdownLinkText.ts` — parse segments, hit-test, URL allowlist.
- `packages/excalidraw/renderer/staticSvgScene.ts` — SVG export for text.
- `packages/excalidraw/components/App.tsx` — pointer hover and click to open links.

## Changes Required

- **markdownLinkText.ts (new):** Parse lines for `[label](url)`, validate URLs via `normalizeLink`, reject dangerous schemes; expose hit-test using the same layout as canvas (`measureText`, line height, alignment).
- **renderElement.ts:** When a line contains valid link segments and the line is LTR, draw segments (plain vs link color + underline); otherwise keep a single `fillText` per line.
- **staticSvgScene.ts:** Emit `<a xlink:href>` with `<tspan>` children for link segments so exports stay clickable.
- **App.tsx:** After resolving the top-most element under the pointer, if it is a text element and hit-test returns a URL, set cursor to pointer and open that URL on click (reuse `window.open` + `noopener` like element links).

## Non-goals

- Do not add full Markdown (bold, lists, headings).
- Do not change the separate “link” property UI or behavior for non-text elements.
- Do not change text-editing UX (wysiwyg remains plain `[label](url)` text).
- Do not add RTL-specific link layout in this change (RTL lines stay plain text rendering).

## Edge Cases

- Malicious or unsupported URLs (`javascript:`, invalid) stay literal text, not links.
- Empty label `[]()` or broken syntax: no link styling.
- Mixed lines: only lines matching the pattern get segmented rendering.

## Constraints

- Link color follows existing hyperlink blue; underline indicates clickability.
- URLs must pass existing `normalizeLink` / sanitization from `@excalidraw/common`.

## Acceptance Criteria

1. Text `Hello [Excalidraw](https://excalidraw.com) end` draws `Excalidraw` as a styled link; other text uses normal fill.
2. Clicking the link region opens `https://excalidraw.com` in a new tab (`target` behavior consistent with existing external links).
3. `yarn test` and `yarn test:typecheck` pass; new unit tests cover the parser and URL gating.
