## Problem Statement

When a user selects a group and presses `Enter`, nothing group-related happens.
The only way to enter a group's edit mode is to double-click one of its child elements.
This forces mouse-only interaction and is inconsistent with other element types that already use `Enter` to enter edit mode (text containers, frames, linear elements).

## Goal

Allow keyboard-first users to enter group editing mode by pressing `Enter` when a group is selected, selecting all child elements of that group.

## Acceptance Criteria

| AC1 | Pressing `Enter` when a group is selected enters group edit mode (`editingGroupId` is set) | Inspect React state; the selection outline changes to per-element selection |
| AC2 | All elements inside the group become selected after pressing `Enter` | All child elements show selection handles |
| AC3 | Pressing `Enter` on a single (non-grouped) element still triggers the existing behaviour (text editing, linear editor, frame edit) | Existing test suite passes |
| AC4 | Pressing `Enter` when there is no selected group does nothing beyond the existing behaviour | Existing test suite passes |
| AC5 | The shortcut appears in the Help dialog | Visual check in the app |
| AC6 | All existing tests pass | `yarn test` green |

## Out of Scope

- Nested groups: only the outermost selected group is entered (same as double-click).
- Cycling through nested levels with repeated `Enter` presses (separate issue).
- Mobile / touch behaviour.

## Design

### Approach

Reuse the existing group-editing pathway that is triggered by double-click (`handleCanvasDoubleClick`):

```
selectGroupsForSelectedElements({ editingGroupId, selectedElementIds }, elements, prevState, this)
```

For the `Enter` path we differ from double-click in one way: instead of selecting only the **hit element**, we select **all elements** in the group, which is what the issue description requests.

### State changes

```
appState.editingGroupId  = selectedGroupId   // outermost selected group
appState.selectedGroupIds = {}               // cleared (we're now inside the group)
appState.selectedElementIds = { id1: true, id2: true, … }  // every child element
```

## Implementation

### `App.tsx` — `onKeyDown` Enter handler (≈ line 5162)

**Before the `if (selectedElements.length === 1)` check**, add:

```typescript
const selectedGroupIds = getSelectedGroupIds(this.state);
if (selectedGroupIds.length > 0) {
  const groupId = selectedGroupIds[selectedGroupIds.length - 1];
  const elementsInGroup = getElementsInGroup(
    this.scene.getNonDeletedElements(),
    groupId,
  );
  const allGroupElementIds = elementsInGroup.reduce(
    (acc: Record<string, true>, el) => {
      acc[el.id] = true;
      return acc;
    },
    {},
  );
  this.store.scheduleCapture();
  this.setState((prevState) => ({
    ...prevState,
    ...selectGroupsForSelectedElements(
      {
        editingGroupId: groupId,
        selectedElementIds: allGroupElementIds,
      },
      this.scene.getNonDeletedElements(),
      prevState,
      this,
    ),
  }));
  event.preventDefault();
  return;
}
```

`getElementsInGroup` is already imported. No new imports needed.
