# Spec: Paste tabular data as a rough table

Upstream: [excalidraw/excalidraw#3762](https://github.com/excalidraw/excalidraw/issues/3762)

## Goal

Дати користувачу опцію вставляти табличні дані (TSV/CSV-подібний буфер обміну) як **грубу таблицю** на canvas — сітку з ліній та текстових комірок у стилі Excalidraw — а не лише як графік або суцільний plain text.

## Context

- Сьогодні paste з «табличним» текстом обробляється в [`packages/excalidraw/components/App.tsx`](../../packages/excalidraw/components/App.tsx) через `tryParseSpreadsheet`; при успіху відкривається діалог `openDialog.name === "charts"` ([`PasteChartDialog`](../../packages/excalidraw/components/PasteChartDialog.tsx)).
- Парсер у [`packages/excalidraw/charts/charts.parse.ts`](../../packages/excalidraw/charts/charts.parse.ts) будує структуру для **діаграм** і вимагає **числових** значень у відповідних колонках. Текстові таблиці (усі комірки не числа) дають `ok: false` і **не** потрапляють у діалог — вставка йде далі по ланцюгу (наприклад, як звичайний текст).
- Референс-реалізація: відкритий upstream PR [#6133](https://github.com/excalidraw/excalidraw/pull/6133) (кнопка таблиці в тому ж діалозі, рендер сітки).

## Non-goals

- Повноцінний «table object» з редагуванням комірок як у FigJam — лише група примітивів при вставці.
- Підтримка складних форматів (Excel binary, HTML tables з буфера) — поза межами, якщо явно не погоджено.
- Зміна семантики `tryParseSpreadsheet` / існуючих тестів діаграм без потреби.
- Розділювач «пробіли між колонками» для довільного тексту — ризик хибних спрацювань; за замовчуванням орієнтир як у поточному парсері: tab, comma, semicolon.

## Acceptance Criteria

1. **Текстова таблиця** (мінімум 2×2, стабільна кількість колонок, розділювачі як у поточному spreadsheet paste) при вставці відкриває той самий діалог paste (charts), з опцією вставити **rough table**.
2. **Числова таблиця**, яка вже розпізнається як `Spreadsheet`, залишає доступними **існуючі** прев’ю графіків (bar / line / radar за правилами `isSpreadsheetValidForChartType`) і додає опцію **таблиці** (сітка з тих самих або узгоджених клітинок — узгодити в імплементації).
3. Вставлена таблиця — набір елементів Excalidraw (лінії сітки + текст у комірках), візуально узгоджена зі стилем rough/chart helpers.
4. **Plain paste** (`isPlainPaste`) не ламається: табличний діалог не відкривається там, де зараз очікується необроблений текст.
5. Нові рядки локалізації для кнопки/aria; аналітика (`trackEvent`) для події вставки таблиці за узгодженою схемою.
6. `yarn test:typecheck` та `yarn test:update` проходять після змін.
