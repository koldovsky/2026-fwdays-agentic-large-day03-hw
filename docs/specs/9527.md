# Spec: Display Error Message for Invalid Hex Color Input

## Goal
When a user enters an invalid color code in the color picker, they receive
immediate inline feedback explaining that the value is not valid.

## Component / Module
Color picker — hex color input field.

## Input / Props / Request

The user types a value into the hex color input field. The input is considered:

**Valid** when:
- The value is a recognized color in any supported format (hex, named color, rgb, etc.)
- The field is empty

**Invalid** when:
- The value contains characters not allowed in a hex color code
- The value has the wrong number of characters for a hex code
- The value is not a recognized color name or format

## Output / Behavior

| Scenario | Expected behavior |
|----------|-------------------|
| User types a valid color | Color updates immediately; no error shown |
| User types an invalid value | Color does not change; an error message appears below the input field |
| User clears the field | Color does not change; no error message shown |
| User leaves the field while an invalid value is entered | Field resets to the last valid color; error message disappears |
| Color is updated from elsewhere in the UI | Any displayed error clears; field shows the new valid color |

The error message reads: **"Invalid color"**

## Edge Cases

- Typing character by character through an invalid intermediate state (e.g. building up a hex code) — error appears while the value is incomplete, clears as soon as the value becomes valid.
- Pasting an invalid value and immediately clicking away — field reverts to the last valid color with no lingering error.
- Whitespace-only input — treated as empty; no error shown.

## Constraints

- The color does not change while the user is typing an invalid value — the
  last valid color is always preserved.
- The input field remains editable at all times; invalid input is never
  blocked or stripped while the user is actively typing.
- The error message appears inline, directly below the input field — no
  popups, toasts, or dialogs.
- The feature applies to the hex input field only. Other color input methods
  (color slettes, eyedropper, preset swatches) are out of scope.

## Non-goals

- Suggesting corrections or valid alternatives to the user.
- Validating colors entered through any method other than the hex text field.
- Translating the error message into languages other than English in this release.

## Acceptance Criteria

1. Typing an invalid value into the hex field displays the message "Invalid color"
   below the field without changing the active color.

2. Typing a valid value after an invalid one removes the error message and
   updates the active color.

3. Clearing the field completely shows no error message.

4. Clicking or tabbing away from the field while it contains an invalid value
   resets the field to the last valid color and removes the error message.

5. No existing color picker functionality is broken by this change.
